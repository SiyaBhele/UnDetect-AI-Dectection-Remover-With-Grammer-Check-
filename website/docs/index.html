Help, features & privacy

Call Text Cleaner is a small, transparent text-formatting utility. It does not identify AI writing, rewrite style, or predict how a detector will classify a document.

What local cleanup changes

  • Replaces U+200B–U+200D, U+FEFF, U+202F, U+00A0 and U+00AD characters with regular spaces.
  • Removes complete lines beginning with Phase [number]: or Execution Log:, ignoring case.
  • Removes Markdown bold markers from titles of the form **Title**:.
  • Trims line-edge spaces, collapses repeated horizontal spaces, and reduces runs of blank lines.

Review and export

After selecting Clean and compare, use the two result tabs to inspect the cleaned text or compare the original and cleaned versions side by side. Copy or download the cleaned text when you are satisfied.

Optional grammar service

The LanguageTool checkbox is off by default. When selected, the cleaned text is sent from your browser to the public LanguageTool API for suggestions (maximum 20,000 characters). Suggestions are displayed for your review and are not applied automatically. A network or service error does not undo local cleanup.

Privacy

Without grammar checking, text is processed in the browser and is not uploaded by this static website. Downloading is initiated locally. Selecting grammar checking sends the text to a third party. Hosting the website on a web server may have its own access logs.

Android app

The Android APK packages this same website in a local WebView, so artifact cleanup and comparison work offline. The internet permission is used only if you explicitly select the optional LanguageTool check. The APK is a debug build and is not published through an app store.

To rebuild the APK from the workspace folder, run sh android/build-apk.sh. To install it on an attached Android device and launch it, run sh android/build-apk.sh --install. The build script caps Java's heap at 4 GB.

Important: These rules only handle the specific formatting patterns listed above. Unicode characters and writing styles do not prove who authored a text, and cleanup cannot guarantee any AI-detector result.
